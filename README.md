# 速记网页

手机端随手记，导出 JSON 粘给 Agent，由 Agent 按 `AGENTS.md` 的 A7 建成笔记。

| 文件 | 作用 |
|:--|:--|
| `index.html` | 整个应用。无依赖、无框架、无 CDN |
| `sw.js` | 离线缓存。没有它网页也能用，只是断网打不开 |
| `manifest.webmanifest` | 让「添加到主屏幕」像 App 一样全屏运行 |

---

## ⚠️ 部署前必读：不要从知识库仓库部署

本知识库的 `10_工作与编程/`、`11_职业方向/` 可能包含公司业务信息（见 `AGENTS.md` A8）。

**GitHub Pages 没有访问控制，公开仓库 = 全世界可读。** 如果直接把知识库仓库开成 public 来部署，等于公开了全部工作笔记。

所以：**新建一个独立仓库，只放这三个文件。**

## 部署（GitHub Pages）

1. 在 GitHub 新建仓库，**名字取随机一点**（例如 `qn-7x2k`，不要叫 `quicknote`）。URL 本身就是唯一的访问凭据。
2. 把本目录下的 `index.html`、`sw.js`、`manifest.webmanifest` 三个文件上传到仓库根目录。
3. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`，目录 `/ (root)`，保存。
4. 等 1~2 分钟，拿到 `https://<用户名>.github.io/<仓库名>/`。

**关于隐私：** 你记的内容只存在手机浏览器的 localStorage 里，**不会上传到任何服务器**，GitHub 也看不到。公开的只有页面本身——也就是那些分类名（外套、绮罗、整牙……）。介意的话用 Cloudflare Pages + Access，可以加一层登录。

**iOS（Safari，必须是 Safari）**
分享按钮 → 添加到主屏幕。

**Android（Chrome）**
右上角菜单 → 添加到主屏幕 / 安装应用。

装完从桌面图标打开，没有地址栏，和原生 App 一样。

## 日常流程

```
手机随手记  →  攒几条  →  导出页点「复制 JSON」
          →  粘到和 Agent 的对话里，说「处理速记」
          →  Agent 建好笔记并报告
          →  回手机点「把这些标记为已入库」
```

**最后一步不能省。** 不标记的话，下次导出会把同样的内容再导一遍，Agent 就会建出重复笔记。

## 设计说明

**为什么按类型动态显示字段**

选「想买的衣服」才出现品牌和价格，选「容貌开销」才出现周期和摊销年数。这样表单永远只有 4~6 项，手机上不用翻。

更重要的是，它能在录入时就拿到那些**原本要 Agent 回头追问**的信息：

- 选了「衣·绮罗」会强制要求选子品类（Pantyhose / Underwear / Leotard / Stocking & Socks）
- 选了「容貌开销」会强制要求选周期，选「一次性」才追加摊销年数

这三项是 `AGENTS.md` A7 里列的「必须追问」字段。在手机上点两下就解决了，省掉一轮来回。

**为什么归类带前缀**

`衣·` `技·` `容·` `妆·` `题·`。前缀决定笔记 type 和存放目录，后半截决定 `part` / `category` / `look` 字段。Agent 靠前缀路由，不用猜。

**为什么不支持传图**

手机上把图塞进网页存储，会迅速撑爆 localStorage（通常只有 5~10MB）。正确做法是在相册里给照片打收藏标记，表单里勾「拍了照片」，入库时 Agent 会把这些条目列出来提醒补图。

**草稿自动保存**

输入过程中切到别的 App、来电话、手滑关掉，内容都还在。下次打开自动恢复。

## 数据安全

数据只在这台手机的浏览器里，**以下操作会全部丢失**：

- 清除浏览器数据 / 清缓存
- 卸载浏览器、换手机
- iOS：Safari 对长期不用的站点会自动清理存储（约 7 天无访问）
- 无痕 / 隐私模式下记的东西，关掉窗口就没了

**所以：每周在「导出 → 备份与恢复」点一次「导出全部」，把文件扔进 `00_Inbox/`。**

恢复时把备份 JSON 粘进「粘贴 JSON 恢复」即可，按 `id` 去重，不会覆盖现有记录。
