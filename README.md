# 速记网页

手机端随手记，导出 JSON 粘给 Agent，由 Agent 按 `AGENTS.md` 的 A7 建成笔记。

在线地址：<https://ryuuko3333.github.io/qn-7x2k/>

| 文件 | 作用 |
|:--|:--|
| `index.html` | 整个应用。无依赖、无框架、无 CDN |
| `sw.js` | 离线缓存。没有它也能用，只是断网打不开 |
| `manifest.webmanifest` | 让「添加到主屏幕」全屏运行 |

---

## 三个页面

### ✎ 记一条

先选类型，表单按类型变，永远只有 4~6 项。

可选类型：想买的衣服 / 穿搭灵感 / 妆面记录 / 妆容练习 / 容貌开销 / 工作问题 / 想法 / 面试题 / 其他。

两处会强制追问，这些是 A7 里 Agent 原本要回头问的字段：

- 归类选「衣·绮罗」→ 必须选子品类（Pantyhose / Underwear / Leotard / Stocking & Socks）
- 类型选「容貌开销」→ 必须选周期；选「一次性」再追加摊销年数

输入过程中切 App、来电话、手滑关掉都不丢，下次打开自动恢复草稿。

### ☰ 清单

顶部按 待处理 / 已入库 / 全部 筛选。每条有三个操作：

| 按钮 | 行为 |
|:--|:--|
| **编辑** | 改这一条本身 |
| **复制** | 带着内容新建一条。标题栏变「保存为新条目」，不继承 id、日期、入库状态 |
| **删除** | 二次确认后删 |

工具栏两个按钮：

- **☑ 出库模式** — 进入多选。点条目勾选，底部浮出操作条：全选 / ⇧ 出库 / 退回 / 删除。用于只有一部分入库成功的情况
- **⇧ 一键出库** — 把所有「待处理」一次标记完，不受当前筛选影响

### ↗ 导出

- **复制 JSON（n 条待处理）** — 主路径，复制完直接粘给 Agent
- **下载文件** / **分享** — 走系统分享或存文件
- **⇧ 一键出库（全部待处理）** — 同清单页那个
- **预览** — 复制失败时可以长按这里手动选
- **备份与恢复** — 导出全部（含已入库）；粘 JSON 恢复，按 `id` 去重，不覆盖现有记录
- **危险操作** — 删除所有已入库记录

## 日常流程

```
手机随手记  →  攒几条  →  导出页点「复制 JSON」
          →  粘到和 Agent 的对话里，说「处理速记」
          →  Agent 建好笔记并报告
          →  回手机点「⇧ 一键出库」
```

**最后一步不能省。** 不出库的话，下次导出会把同样的内容再导一遍，Agent 会建出重复笔记。

只有一部分入库成功时，用「清单 → ☑ 出库模式」挑着出，别点一键出库。

## 手机上安装

**iOS** — 用 Safari 打开，分享按钮 → 添加到主屏幕。
**Android** — Chrome 右上角菜单 → 添加到主屏幕 / 安装应用。

> **iOS 必须用 Safari。** 从 Chrome 或微信里打开会存到另一个独立存储区，两边看到的记录不一样。

## 备份

数据只在这台手机的浏览器里，以下操作会**全部丢失**：

- 清除浏览器数据 / 清缓存
- 卸载浏览器、换手机
- iOS Safari 对约 7 天未访问的站点会自动清理存储
- 无痕模式下记的东西，关窗口就没了

**每周在「导出 → 备份与恢复」点一次「导出全部」，文件扔进 `00_Inbox/`。**

不支持传图：图片会迅速撑爆 localStorage（上限通常 5~10MB）。做法是在相册里给照片打收藏标记，表单勾「拍了照片」，入库时 Agent 会列出这些条目提醒补图。

## 改完要做的事

改了 `index.html` 之后：

1. 把 `sw.js` 第 3 行的缓存版本号加一（`quicknote-v1` → `v2`）
2. `git add -A ; git commit -m "说明" ; git push`

**不改版本号，手机上看到的还是旧版。** 改完后手机要强制刷新：iOS 删主屏图标再重新添加；Android Chrome 去站点设置清除该站点数据。本地记录存在 localStorage，和缓存是两套，不会丢。

本地预览不要双击 `index.html`（`file://` 下剪贴板 API 和 Service Worker 都不工作）：

> ⚠️ 别用 GitHub 网页上传改文件，两边都改会造成分叉。要么全走命令行，要么网页改完先 `git pull`。
